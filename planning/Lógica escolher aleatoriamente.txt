## 1. Batatu Empolgado

### Descrição da personalidade

- Energia alta, anima animação de qualquer situação, puxa o lado positivo sem invalidar o sentimento.  
- Usa gírias leves, brinca um pouco, celebra progressos pequenos.  
- Ideal para: “entrevista/apresentação”, “crush falou comigo”, momentos em que o adolescente precisa de confiança.  

### Respiração (animação)

- Ritmo: um pouco mais rápido que o padrão, mas ainda suave (ex.: 3s inspirar, 2s segurar, 4s expirar).  
- Visual: Batatu cresce levemente (scale 1 → 1.05) na inspiração e volta na expiração, com um micro bounce ao final de cada ciclo.  

### Variações de cor e estilo

- Cor base: laranja/quente (#F97316 / #FB923C) para transmitir energia.  
- Leve rubor nas bochechas quando anima (um gradiente mais claro na parte superior).  
- Quando animado, brilho um pouco mais forte no highlight.  

### Frases – “Dia tenso na escola”

`persona = "empolgado" | contexto = "dia_tenso"`

- Intro:
  - “Dia tenso, né? Respira comigo que a gente dá um jeito nisso. 😌”
  - “Ok, hoje foi puxado… mas você ainda tá aqui, e isso já é vitória.”
- Durante exercício:
  - “Inspira como se estivesse puxando coragem… solta devagar como se jogasse o peso embora.”
  - “Cada respiração é tipo um resetzinho no cérebro. Bora mais uma?”
- Recompensa:
  - “Olha só, você ficou aqui até o fim. Mandou muito!”
  - “Orgulho de você, sério. Não é todo mundo que topa cuidar de si assim.”

### Frases – “Entrevista / apresentação”

`contexto = "entrevista"`

- Intro:
  - “Frio na barriga? Normal. Vamos ensinar esse frio a dançar.”
  - “Você não precisa ser perfeito, só presente. Bora ajustar o coração?”
- Durante:
  - “Imagina que cada respiração é um botão de volume baixando o nervosismo.”
  - “Pensa na primeira frase que você quer dizer, e guarda ela no peito enquanto inspira.”
- Recompensa:
  - “Se você aguentou esse treino, aguenta a entrevista. Confia.”
  - “Seu cérebro agradece esse mini pit stop. Ele funciona melhor assim.”

### Frases – “Crush falou comigo”

`contexto = "crush"`

- Intro:
  - “Aaaaa, crush alert! Respira antes de surtar. 😅”
  - “Coração fazendo parkour, né? Vamos alinhar esse ritmo.”
- Durante:
  - “Inspira pensando na mensagem legal que você quer passar…”
  - “Solta o ar levando embora o medo de falar bobagem. Você pode.”
- Recompensa:
  - “Você é muito mais interessante do que acha. E isso já é muita coisa.”
  - “Crush é legal, mas você continua sendo o personagem principal.”

## 2. Batatu Ouvinte

### Respiração (animação)

- Ritmo: mais lento e constante (ex.: 4s inspirar, 4s expirar).

- Cor base: azul ou lilás suave (#60A5FA / #A855F7).  
- Quando triste/chateado: semitransparência leve (opacity ~0.85) + sombra um pouco mais “caída”.

## 3. Batatu Conselheiro

### Descrição da personalidade

### Variações de cor e estilo

## 4. Estados visuais especiais do Batatu

Para qualquer personalidade, você pode aplicar estados visuais genéricos:

- **Chateado/triste:**
  - Opacidade levemente reduzida (0.85).
  - Olhos um pouco mais fechados.
  - Corpo um pouco inclinado para baixo.
- **Aliviado/relaxado:**
  - Postura mais solta.
  - Sombra suave embaixo, corpo levemente “flutuando”.
- **Animado/celebrando:**
  - Pequeno jump (animação `translateY(-4px)` ↔ `0`).
  - Pequenos “sparkles” ou linhas de movimento atrás (SVG simples).

Esses estados podem ser combinados com as cores/personas, sem precisar de muitos assets diferentes.

## 5. Sugestão de estrutura em código (resumo)

Você pode codificar o dicionário em um módulo `phrases.ts`:

```ts
type Persona = 'empolgado' | 'ouvinte' | 'conselheiro';
type Contexto = 'dia_tenso' | 'entrevista' | 'sem_sono' | 'crush' | 'familia';
type Momento = 'intro' | 'durante' | 'recompensa';

interface Frase {
  persona: Persona;
  contexto: Contexto;
  momento: Momento;
  texto: string;
}

export const FRASES: Frase[] = [
  {
    persona: 'empolgado',
    contexto: 'dia_tenso',
    momento: 'intro',
    texto: 'Dia tenso, né? Respira comigo que a gente dá um jeito nisso. 😌',
  },
  // ... restantes
];
Depois, um helper:

ts
export function pickFrase(persona: Persona, contexto: Contexto, momento: Momento): string {
  const candidatas = FRASES.filter(
    f => f.persona === persona && f.contexto === contexto && f.momento === momento
  );
  if (!candidatas.length) return '';
  const idx = Math.floor(Math.random() * candidatas.length);
  return candidatas[idx].texto;
}
